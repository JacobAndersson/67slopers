# Rivet asset kit

Generated by `design/rivet/tools/kit.py`; edit the brand sources, not these files.

- `logo/`: symbol (Night, Snow, Glow), wordmark, horizontal and stacked lockups (Night, Snow), the
  Snow lockup with a Glow symbol for Night grounds, and the app icon. SVG masters plus 1600 px PNGs.
  The wordmark is artwork: place these files, never retype it.
- `tokens/`: `rivet.tokens.json` (colours, scales, light and dark roles, radii, motion, the Glow rule),
  `rivet.css` (CSS variables with a dark-mode block) and `tailwind.rivet.js` (Tailwind / NativeWind).
- `icons/`: the custom hangboard and spray-board icons, Regular and Fill, on Phosphor's 256 grid.
- `fonts/`: Nunito 300–900 (SIL Open Font License).
- `posters/`: print-size poster artboards (1200 × 1800 px masters).
- `motion/`: loading and startup animations and the brand film (`film.html`, preview `rivet-film.webp`).

Glow is the colour of the hang. It fills the Hang screen and the app icon, and colours the symbol on
Night. Nowhere else.
